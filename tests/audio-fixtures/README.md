# Audio fixtures

Synthesised test and demo audio, stored in Git LFS. Generated by `tools/make-fixtures` from fixed formulas and a fixed
noise seed; a test regenerates the set and checks that every file decodes to the same samples as the committed one.

Regenerate (only when a fixture design changes, then commit the result):

    MakeFixtures tests/audio-fixtures

Two large cases are never committed. They are generated when needed:

    MakeFixtures --long %TEMP%\long      writes texture-10min.wav and toolong-31min.wav

| File | What it is | Used for |
|---|---|---|
| `drums-loop-120.wav` | 2-bar drum loop, 120 BPM, 44.1 kHz stereo 16-bit, exactly 176400 frames, sharp onsets | main demo loop, WAV import, MP3 alignment reference |
| `drums-loop-120.aiff` | the same loop as AIFF | AIFF import |
| `drums-loop-120.mp3` | the same loop encoded by LAME 3.100 with the Xing/Info + LAME tag | MP3 gapless trim (tag path) |
| `drums-loop-120-notag.mp3` | the same loop encoded by LAME without any tag | MP3 trim of 1105 frames (no tag) |
| `kick.wav` | 0.4 s kick, mono | one-shot category, short sounds |
| `bass-phrase.flac` | 2 s bass line, 48 kHz mono FLAC | FLAC import, non-44.1 kHz rate kept |
| `pad-chord.ogg` | 3 s A minor chord, Ogg Vorbis | OGG import, category change demo |
| `texture-60s.flac` | 60 s evolving stereo texture | long waveform thumbnail |
| `5ch-tone.wav` | 1 s, 5 channels | down-mix to stereo with a toast |
| `corrupt.wav` | 2 KB of seeded noise with a `.wav` name | failed import leaves no trace |
| `not-audio.txt` | a text file | unsupported file type |

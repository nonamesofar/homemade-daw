# Tasks

M3 is built as four demos on one branch (`change/m3-sample-editor`), checked by the PO one at a time, with one PR at the end. Each group ends with a demo script and a PO acceptance task. Build: `scripts/build.ps1` or `cmake --build --preset windows-msvc-debug`; tests: `ctest --preset windows-msvc-debug -LE hardware`. Tests that open a real audio device carry the `hardware` label, timing checks the `perf` label, and the analysis accuracy suite the `slow` label.

## 3. D3: Play the pads

- [x] 3.1 `render::SliceRenderer` (design D6): region read, reverse, Signalsmith pitch with latency compensation (skipped at 0 st), r8brain resample, gain, 1 ms edge fades; `SliceBuffer`. Verify: unit tests: pitch 0 at equal rates is sample-identical to the region (except the edge fades); +12 st keeps the length and doubles a sine's frequency; reverse reverses; 48 -> 44.1 kHz keeps a sine's pitch; a 2 s +7 st render under 100 ms (`perf`; spike 1.1 showed the original 20 ms is out of reach)
- [x] 3.2 `render::RenderScheduler`: pool, one pending job per slice (latest wins, stale results dropped by generation), priority for played and selected slices, re-render all on a device rate change, 200 MB per-sound budget with on-demand rendering beyond it. Verify: scheduler tests with a fake renderer: rapid parameter changes deliver only the last result; priority order; budget eviction order
- [x] 3.3 `SlicePadPlugin` (design D5): 16 voices, oldest stolen with 3 ms fade, retrigger choke, One-shot / Gate (10 ms release) / Loop (3 ms crossfade), pad event FIFO, `SliceBank` exchange with garbage FIFO, sounding counts for the lights. Verify: engine tests rendering the plugin offline with scripted events: Gate stops 10 ms after release; Loop repeats with no step at the wrap; 17 notes steal the oldest; retrigger has no discontinuity above a threshold; a bank swap while a voice sounds keeps the old buffer playing; no allocation in `applyToBuffer` over 30 s under the debug hook
- [x] 3.4 `engine::PadEngine` facade (design D4): preview edit with one track and the plugin, alive while a project is open, `padOn` / `padOff` / `allOff`, `setBank`, sounding state. - [x] 3.5 Commands for slice settings: `SetSliceParam` for pitch (-24..+24), gain (silence..+24 dB), reverse and play mode with the 500 ms coalesce key. Verify: command tests: two gain changes within 500 ms are one step; values outside the range are clamped; round trip

- [x] 3.7 Docs: AGENTS.md "Pads" rule and design doc §7.4 / §4.1 updated to the preview-edit pad engine (design D4); ROADMAP decisions log line. Verify: AGENTS.md, design doc and design.md D4 say the same
- [ ] 3.8 PO demo D3 accepted (script below)

**Demo D3 script:** open `break-90` sliced at 1/4. Press Z X C V: slices 1 to 4 play and their pads light. Play the song and finger-drum on the keys over it. Hold A on a Gate slice: it stops when released; set slice 6 to Loop and hold its pad: it repeats.

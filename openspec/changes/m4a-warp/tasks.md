# Tasks

M4a is built as three demos on one branch (`change/m4a-warp`), checked by the PO one at a time, with one PR at the end. Each group ends with a demo script and a PO acceptance task. Build: `scripts/build.ps1` or `cmake --build --preset windows-msvc-debug`; tests: `ctest --preset windows-msvc-debug -LE hardware`. Tests that open a real audio device carry the `hardware` label, timing checks the `perf` label.

## Workflow follow-up

- Open the PR with the two sections required by AGENTS.md (what changed for the user; technical summary). It also carries the M3 archive edits that were uncommitted on `main` when this branch was made.
- Run `/opsx:verify`, then `/opsx:archive` after the PR is merged; check that the ROADMAP M4a items are ticked.
- Propose `m4b-export` (export, autosave and recovery, audio settings, installer, MVP exit) next.
